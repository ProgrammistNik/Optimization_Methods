# lab4 — Пошаговое управление инвестиционным портфелем

Динамическое программирование, соотношение Беллмана.

## Задача

Начальный портфель: ЦБ1 = 100, ЦБ2 = 800, депозит = 400, свободные средства = 600.
Три этапа с вероятностями благоприятной, нейтральной и негативной ситуации.
Нужно найти план покупок и продаж пакетами по 25 процентов от начального объема,
чтобы максимизировать ожидаемый доход.

## Запуск

```bash
cd lab4
python3 portfolio_dp.py
```

Сравнение критериев:

```bash
python3 portfolio_dp.py --all-criteria
```
