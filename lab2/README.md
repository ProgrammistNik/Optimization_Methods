# lab2 — Метод ломаных (Пиявский)

Поиск глобального минимума липшицевой функции на отрезке.

## Запуск

```bash
pip install -r requirements.txt
python3 broken_line.py
```

## Что делает программа

- принимает функцию (строка), отрезок `[a, b]`, точность `eps`
- оценивает `L` с уточнением сетки до сходимости
- ищет минимум методом ломаных (пересечения нижних оценок)
- печатает `x*`, `f(x*)`, число вызовов `f`, `status`, время
- демо 1: Растригин (несколько локальных минимумов)
- демо 2: `x + sin(pi*x)`
- графики: `lab2_demo_rastrigin.png`, `lab2_demo_sin.png`
