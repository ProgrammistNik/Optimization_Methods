# lab2 — Метод ломаных (Пиявский)

Поиск глобального минимума липшицевой функции на отрезке.

## Запуск

```bash
pip install -r requirements.txt
python3 broken_line.py
```

## Что делает программа

- принимает функцию (строка), отрезок `[a, b]`, точность `eps`
- оценивает константу Липшица `L`
- ищет минимум методом ломаных (через пересечения нижних оценок)
- печатает `x*`, `f(x*)`, число итераций, время
- сохраняет графики: `lab2_demo_sin.png`, `lab2_demo_rastrigin.png`
